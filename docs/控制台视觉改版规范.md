# 新控制台视觉改版规范（对齐旧版自我校准控制台）

目标：新控制台（`console.html`：生产 / 零件库 / 记录 / 设置）**全部功能、交互、数据、文案含义保留**，视觉和布局改成旧版面板（`index.html` + `app.css` + `modules/theme/theme.css`）那套工业仪表风格。旧版是唯一参照，遇到不确定先去旧版找同类元素照抄做法。

外部依据（只取原则，不抄任何产品外观）：ISA-101 高性能 HMI——灰阶底、颜色只表达异常与状态、平面 2D、数据最亮容器最暗；Siemens iX——语义 token、直角或极小圆角、严重度颜色必须配文字。

## 一、硬规则

1. 只用 `tokens.css` 的变量（颜色、字号、间距、圆角、控件高度）。不新增 hex，不新增状态颜色。
2. 不改任何 `.js` 的行为逻辑、数据流、事件、状态机。为了套样式可以在 view 里加/改 class、包一层容器、调整 DOM 顺序，但 `data-*` 属性、`aria-*`、`role`、按钮文案、测试依赖的选择器必须保留。改之前先 `grep tests/` 看测试用了哪些选择器。
3. 不引入外部字体、CDN、图片。
4. 桌面一屏（1280×720 起）不出现整页滚动，内容区内部滚动；≤1080 单列可滚；≤720 顶栏两行。

## 二、外壳（顶栏 + 页面容器）

照旧版 `header` 做：
- 高 `--header-h`，实底 `--bg`，下边 1px `--line`，无毛玻璃。
- 左：品牌 `■ ReArm`（8×8 方块 `--text` 色 + 文字 `--fs-lg` 600、字距 .06em）+ 小字副标题「日新臂 · 生产控制台」(`--mute`, `--fs-sm`)。去掉现在的白底 logo 块。
- 连接状态：7px 圆点（已连 `--ok`）+「实时连接」+ `.pill` 样式的数据来源（如「模拟」「本地演示」）。现有 `console-status`（待命 等）改为这种低调 pill，或并入状态区。
- 导航：文字标签 + 选中项 2px 底边线（`--text`），未选 `--mute`，**不用白底块**。
- 右侧按钮：细线描边透明底、`--radius`；「一键重置」普通按钮；「急停」保持 `--estop` 实底白字，尺寸可与旧版一致（不再比其他按钮高一倍，但保证最小 40px 高、最醒目）。
- 页面容器：去掉现在包住整页的大卡片，改为 `padding: 12px 16px` 的网格，页面内容由多张卡片拼成，卡片间距 `--gap`。

## 三、通用组件（写在 `modules/console/console.css`，类名统一 `c-` 前缀）

- `.c-card`：`--panel` 底，1px `--line`，`--radius`。
- `.c-card-head`：卡片标题行，`--fs-sm`、字距 .08em、`--sub`；左侧 6×6 空心方块（1px `--mute` 描边）；右侧 `.c-aside` 小字 `--mute` `--fs-xs`；下边 1px `--line`；padding `9px var(--pad)`。
- `.c-card-body`：padding `0 var(--pad) var(--pad)`，可内部滚动。
- `.c-kpis`：KPI 条，多格之间只有 1px `--line` 间隔（父元素 `background: var(--line); gap:1px`）。格内：标签 `--fs-xs` `--sub` 字距 .08em；数值 `--mono` `--fs-kpi-wide` 500；单位 small `--mute`；说明行 `--fs-xs` `--mute`。空值显示「—」。
- `.c-viewport`：画面区（3D 孪生、观察画面）。`--video` 底、1px `--line2`，四角 14px 取景角标（照抄 theme.css 的 `.cam:after` 写法）。
- `.c-chip`：画面四角浮标，`rgba(6,8,10,.86)` 底、1px `--line2`、2px 圆角、`--fs-sm`；前置 7px 状态圆点（ok/busy/bad 三色，busy 闪烁）。位置类 `.tl .tr .bl .br`，距边 14px。
- 表格：表头 `--fs-xs` `--mute` 400 字距 .3px；行高紧凑 `6–8px` padding；1px `--line` 分隔；数字列 `--mono` 右对齐；选中/当前行左侧 2px `--text` 内阴影 + 亮字，不铺色块。
- `.c-tag`：1px 描边、2px 圆角、`--fs-xs`；ok/bad/cur 只换描边与字色。
- 按钮：`.c-btn` 细线透明；`.c-btn.primary` 反白实底（`--accent` 底 `--on-accent` 字）；disabled 0.45 透明。
- 分段切换（零件/配方 这类）：照旧版 `.tabs`，纯文字 + 选中亮字/底线，不用按钮块。
- 空状态：`--mute` `--fs-sm` 居中，padding 22px。
- 对话框、tooltip：照旧版 `.modal/.tip`，`--radius`，阴影 `0 12px 32px rgba(0,0,0,.6)`，遮罩 `rgba(0,0,0,.72)` 无模糊。

## 四、各页布局

### 生产（对标旧版主页）
桌面一屏网格：
- 左大块 `.c-viewport`：3D 数字孪生，占宽约 60%。四角 chip：左上 当前状态（待命/运行中/已急停）、右上 配方名、左下 数据来源（模拟）、右下 当前步骤或「等待开始」。保留现有拖动/缩放/双击复位提示。
- 右列自上而下：
  1. `.c-kpis` 四格：完成套数、一次通过率、最近检查偏差（mm）、本套用时（若无对应数据就用现有已有的指标，不造数据）。
  2. 卡片「配方」：配方下拉 + 开始按钮（primary），一行排布。
  3. 卡片「生产步骤」：步骤列表做成紧凑行，每行：序号（mono）+ 名称 + 状态点；当前步骤亮字 + 左侧 2px 线，已完成 `--sub`，未开始 `--mute`。
  4. 卡片「观察画面」：内部是 `.c-viewport`（含已做好的摄像头视频口和识别标签），卡片底部一行检查结果。
- 观察画面保留视频接口（`setCameraSource`、`?camera=`）与「未接入摄像头」标记。

### 零件库
- 顶部一行：页面分段切换「零件 / 配方」（文字 tab 样式）+ 右侧「新增零件」primary。
- 左：列表卡片（`.c-card` + 表格），名称不再是带框按钮，改为整行可点（hover `--hover`，选中左侧 2px 线），外形缩略图缩小到 28px 线框；编号、版本、收录时间 mono。
- 右：详情卡片（选中零件的文档/训练记录，原本已有的 part-doc / recipe-doc / training-record 内容），未选中时空状态提示。
- 三步新增流程沿用现有 stepper，样式照旧版 `.steps`。

### 记录
- 两张并排卡片「生产记录」「训练记录」，标题用 `.c-card-head`，右侧 aside 显示条数。
- 表格照通用表格规范，数字列 mono 右对齐，结果列用 `.c-tag`。
- 若有汇总数据（总套数、通过率、平均偏差等，仅限现有数据能算出的），顶部加一条 `.c-kpis`。

### 设置
- 「连接」「参数」两张卡片，内容改为键值网格：标签 `--fs-xs` `--sub` 字距，值 mono `--text`；「已连接」用 7px 绿点 + 文字，不整段绿字。
- 页标题旁「只读」用 `.pill`。

## 五、动效（克制、利落、有工业仪表感）

总原则：动效只用于“状态变化”和“空间关系”，时长短、曲线硬朗，不弹跳、不发光、不旋转。全部写成 CSS（transition / @keyframes），JS 只负责切换 class 或 data 属性。必须提供 `@media (prefers-reduced-motion: reduce)` 下全部关闭。

时长与曲线（写成变量放在 console.css 顶部）：`--t-fast:120ms` 悬停/按压；`--t-base:200ms` 状态切换；`--t-slow:320ms` 进场；曲线 `--ease-out:cubic-bezier(.2,.7,.2,1)`；`--ease-in-out:cubic-bezier(.65,0,.35,1)`。

1. 页面进场：切页时各 `.c-card` 依次淡入 + 上移 6px，`--t-slow`，每张卡延迟 40ms 递增（用 `--i` 变量或 nth-child），最多 6 级。
2. 导航：选中底线在 tab 之间滑动（一个独立的指示条元素，transform + width 过渡 `--t-base`），而不是瞬间换边框。
3. 按钮/行：hover 背景和描边 `--t-fast`；按下 `transform: translateY(1px)`；表格行 hover 背景渐变 `--t-fast`。
4. 数值：KPI 数值变化时短暂高亮（文字由 `--sub` 过渡到 `--data`，或底部 1px 线从左扫到右 `--t-slow`），不要做数字滚动。
5. 生产步骤：当前步骤左侧 2px 线从上往下长出 `--t-base`；完成的步骤打勾淡入；进行中步骤的状态点用旧版 `pulse`（1s，opacity .25↔1）。
6. 画面区：`.c-viewport` 首次出现时四角取景角标从中心向四角收拢到位（`--t-slow`）；busy 状态时顶边有一条 1px 的扫描线缓慢从左向右循环（2.4s linear，透明度 .35），idle 时消失。
7. chip 状态切换：圆点颜色过渡 `--t-base`；文字变化用 120ms 淡出淡入。
8. 对话框：遮罩淡入 `--t-base`，面板淡入 + 从 0.98 放大到 1 `--t-base`；关闭反向。
9. 急停：按下后全局红色横幅从顶部滑下 `--t-base`；急停按钮本身不加动画（安全控件不分散注意力）。
10. 零件库选中行：左侧 2px 线淡入，右侧详情卡片内容 120ms 交叉淡入。
