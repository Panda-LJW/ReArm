### A.2 模块化（硬约束）

- 新控制台的全部代码放在 `rearm/ui/static/modules/console/`，目录按 A.4。**一个文件只管一件事**，单个文件超过约 200 行就拆。
- 页面之间不互相 import。页面只依赖 `state/`、`widgets/`、`shell/` 暴露的接口和 `modules/datasource/`、`modules/twin/`、`modules/arm/` 的公开入口。
- 所有数据只走数据源层：视图不直接 `fetch`、不开 WebSocket、不读 `window.__rearmMock`。视图拿到的是 `store` 的状态，发指令只调 `send(cmd, args)`。这样节点④换成真主机时只换数据源。
- 状态归并写成纯函数 `reduce(state, message)`（参考 `modules/trainer/store.js`），不碰 DOM、不读时钟，能在 node 里直接测。
- 每个页面由 `console/main.js` 用 `optional(name, mount)` 的方式单独 try 加载（照 `modules/main.js` 的写法）。任何一个页面或孪生加载失败，只影响它自己：导航、状态标签、急停照常可用。
- 每个视图文件导出 `mount(root, ctx)` → `{ render(state), dispose() }`，渲染合并进 `requestAnimationFrame`，一帧最多一次。
- 样式：每个页面一个 css，只写自己根元素（`[data-page="..."]`）下的规则；颜色、字号、圆角、间距只用 `tokens.css` 的变量，不写死色值和 px 字号，不用渐变和发光。
- 不改 `app.js`、`app.css`、`index.html`、`modules/trainer/`、`modules/guide|theme|focus|presentation/`、`modules/datasource/mock-host.js`。`modules/twin/` 只能按 T3 的方式加可选参数，默认行为逐字节不变。

### A.3 入口怎么接（已定路线）

- 新增 `rearm/ui/static/console.html`，是新控制台的薄外壳，只引 `tokens.css` 和 `modules/console/main.js`。
- `rearm/ui/server.py` 的 `/` 路由：查询串带 `legacy=1` 时照旧返回 `index.html`，否则返回 `console.html`。这是 Python 侧唯一允许的改动，不碰任何指令、急停、WebSocket 逻辑。受影响的旧测试（断言 `/` 返回旧首页的）改成请求 `/?legacy=1`，断言内容不许变弱。
- `index.html` 和它加载的旧面板、训练模块一行不改，`?legacy=1` 的表现和现在完全一样。
- 新控制台不访问 `/ws`、`/api/*`，只用数据源层。默认数据源是 T2 的新模拟主机；`?backend=ws://…` 的真机接入留给节点④，本节点不做、也不留半成品入口。

### A.5 钩子（清单 9.2 之外的补充，脚本和页面都照这个）

| 钩子 | 放在哪 |
|---|---|
| `aria-disabled="true"` | 所有“不能点”的按钮统一用它，不用 `disabled` 属性（否则悬停事件收不到）。点击、回车、空格都不生效 |
| `[role="tooltip"][data-tip]` | 不可用原因的提示框，出现时可见 |
| `[data-count="sets"]`、`[data-count="pass-rate"]` | 完成套数、一次通过率 |
| `[data-result]` | 检查结果，文字是“到位”或“偏差 x.x mm” |
| `[data-check-item]` + `data-ok` | 自检的每一项 |
| `[data-tab="parts|recipes"]` | 零件库的两个分页 |
| `[data-chart="deviation"]` | 偏差曲线的画布或容器 |
| `[data-force]` | 夹持力，文字形如 `12.3 N` |
| `[data-twin-label]` + `data-anchor-x`、`data-anchor-y` | 孪生标签；两个 anchor 是它对应关节在视口里的像素坐标，脚本靠它把鼠标移过去 |
