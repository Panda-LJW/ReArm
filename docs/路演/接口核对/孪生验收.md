# 数字孪生夹头、相机与手指核对

数值核对和网格几何回归通过；全量测试未全绿，浏览器画面和硬件未验收。后端只读，未提交 commit。

## 改前与改后

真机夹爪没有激光；孪生已移除激光头、光束、落点和开关（2026-11-15），实测点与偏差叠加保留。

尺寸单位 mm；夹指外形按末端 X 接近、Y 闭合、Z 厚度排列。

| 项目 | 改前 | 改后 |
|---|---|---|
| TCP 相对名义 tip | X +0.5，轴向一致 | 4×4 单位变换，位置和三轴重合 |
| 相机安装平移 | [-69.5, 0, 40] | [-68.814228, 36.191124, 55.202707] |
| 相机安装旋转 | 单位矩阵 | 后端手眼旋转，OpenCV +Z/-X/-Y 对应渲染 +X/+Y/+Z |
| 简化夹指外包围盒 | 65×12×40，矩形、无 V 槽 | 65×25×40，90° V 槽 |
| customFinger 外包围盒 | 65.5×25×40，STEP 网格 | 65×25×40，与简化路径共用 V 槽外形 |
| 指尖位置 | custom X=+0.5 | 两条路径均 X=0，根面 X=-65 |
| V 槽 | 简化路径无槽；旧 STEP 有槽 | 边 15，角 90°，深 10.60660，口宽 21.21320，平条 0 |
| 全开行程 | 总开口 110，单指 55 | 不变；左右内缘间距 110，外缘在 ±80 |

深度 10.61、口宽 21.21 是后端配置的两位小数；几何按边长 15 和夹角 90° 生成，避免舍入破坏夹角。厚度是 Z 方向的 40，原简化参数中名为 thickness 的 12 实际在闭合 Y 方向，不能描述成“真机厚度从 12 改到 40”。

原 STEP 文件未修改。新 customFinger 显示网格只保留外轮廓，不表示原 STEP 的孔位等细节；两条路径由同一个 createFingerGeometry 生成，防止尺寸再次分叉。

## 完整位姿误差

比较原 FK 对照的 3 组 q，加指定工作位 `[1.6405,-1.6608,-2.2757,1.8915,-0.0063,0.1276]`。平移按欧氏距离，姿态比较完整三轴；报告中保存全部 4×4 矩阵。手眼旋转六位小数略不正交，仅在角度度量时用 SVD 投影到 SO(3)，不改变原始矩阵。

| 比较项 | 改前位置 / 朝向 | 改后四组最大位置 / 朝向 |
|---|---|---|
| end_link 对后端 tip | 本来重合 | 3.69×10⁻¹³ mm / 5.62×10⁻¹⁴° |
| 前端 TCP 对后端 tip | 0.5 mm / 约 0° | 3.69×10⁻¹³ mm / 5.62×10⁻¹⁴° |
| 相机对后端 tip·T_tip_cam | 39.26054 mm / 19.95136° | 3.91×10⁻¹³ mm / 5.10×10⁻¹⁴° |

工作位 TCP 为 `[-21.039344, 283.547857, 336.007539] mm`；相机光心为 `[-51.977325, 318.276743, 419.249837] mm`。相机 OpenCV +Z 光轴在基座中为 `[-0.048519881, -0.054547153, -0.997332093]`。工作位 TCP 位置误差 `3.68×10⁻¹³ mm`，小于 0.5 mm。

`kin6.fk()` 的 tool_x=-105 是另一个偏置点，不是抓取夹头；抓取 tip 是 base·DH1..6·TOOL_DH。TABLE_TIP_Z_MM=3.6 是碰桌时名义夹头的基座 Z，未加到局部 TCP。

完整输出：[孪生对照.json](孪生对照.json)。复跑：`.venv/bin/python scripts/check_twin_vs_backend.py <后端目录>`；可加 `--baseline-params <改前arm-params.js>`。脚本通过后端独立 Python 子进程加载 pick.frames，-B 禁止生成后端 pycache，无硬件访问。
