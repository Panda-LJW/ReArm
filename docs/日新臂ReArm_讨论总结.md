# 日新臂 ReArm：讨论总结

2026-11-13 · 基于《日新臂 ReArm 项目文档》的讨论整理

## 0. 结论先行

- 项目方向可行：用一个普通摄像头让低成本机械臂自己发现"不准了"并自己更新。
- 原方案的主干是**经典参数辨识**（11 个几何参数 + 最小二乘），不是 AI。
- 为了紧扣"模型"和"日日新"，把原文档 8.8 节的"夜间残差学习"从加分项提为主线：机械臂维护一个**自我模型**，并且**每天根据当天数据重新学习一次**。
- 主线成立的前提要先实测：几何校准后，留出姿势上的误差必须明显大于重复精度，否则学习模型学不出提升。

---

## 1. 摄像头能否替代专业标定设备

判断标准：测量设备的精度要比机械臂的重复精度高 3–10 倍；校准后的精度上限就是重复精度。

| | 重复精度 | 普通摄像头（文档估约 0.3 mm，未实测） | 结论 |
|---|---|---|---|
| 低成本舵机臂 | 1–3 mm（齿隙、下垂） | 比臂本身好 3–10 倍 | 够用，瓶颈在臂不在相机 |
| 工业臂 | 0.02–0.05 mm | 比臂差一个量级 | 只能做粗恢复，做不了绝对精度标定 |

- 适用：抓取、搬运、教学、为模仿学习采数据等毫米级场景。
- 不适用：焊接、精密装配。
- 原文档未处理的两点：
  - **镜头畸变**：只用单应矩阵会把镜头畸变（边缘可达约 1 mm）误当成机械臂误差，需先做相机内参标定并去畸变。
  - **演示的伤与日常需求不同**：演示的是 15°、40 mm 这种大而离散的伤；日常的定期校准面对的是 0.5° 级缓慢漂移，难得多，目前没有数据。

---

## 2. 为什么要用模型，传统算法哪里不够

**对几何误差，学习模型不必要，而且更差。**

| | 参数辨识（传统） | 神经网络拟合残差 |
|---|---|---|
| 数据量 | 十几个姿势 | 成百上千发 |
| 泛化 | 全工作空间成立 | 只在采过样的区域可信 |
| 可解释 | "J2 偏了 15°" | 无 |
| 几何一变 | 重拟合几个参数 | 之前学的可能作废 |

学习模型的位置是**补几何公式写不出来的部分**：齿隙、重力下垂、连杆弹性、温漂、松动。正确结构是"物理模型打底，学习模型补小残差"。

注意：齿隙是迟滞，同一关节角因接近方向不同而误差不同，学习模型的输入必须包含**接近方向**。

学习模型真正不可替代的地方还有两处：
1. **感知端**：去掉激光和定位码，直接从图像认出机械臂关节/末端（无标记），传统规则做不了。
2. **开放故障类型**：菜单外的伤无法列举，需要学习。

## 3. 原方案的三层：经典辨识 + 自动诊断 + 状态记忆

| 层 | 负责 | 做法 | 边界 |
|---|---|---|---|
| 经典辨识 | 算得准 | 11 个几何参数，十几发激光，最小二乘 | 精度上限是重复精度；不管齿隙、下垂 |
| 自动诊断 | 知道哪里坏了 | 残差监控 → 假设竞争（BIC）→ 主动挑姿势 → 护栏验证 | 只能在预设的 6 类假设中选 |
| 状态记忆 | 第二次更快 | 每次采纳的参数存版本，3 发探测匹配旧版本直接切换 | 只对离散、会重复的状态有用 |

与传统标定的区别：算法相同，不同在**谁触发、校哪些、结果记不记**。

对应赛题：
- 第二次比第一次有提升 → 状态记忆（60 秒变 5 秒）
- 说明学到了什么 → 自动诊断
- 必要时能回退 → 版本库 + 护栏

## 4. 扣上"模型"与"日日新"

### 4.1 自我模型分两层

```
预测光点 = 几何公式(关节角, 11个参数) + 学习模型(关节角, 接近方向, 负载, 温度)
```

| 层 | 管什么 | 比方 |
|---|---|---|
| 几何公式 | 大的、说得清的：零点、杆长、底座位置 | 知道自己胳膊多长 |
| 学习模型 | 小的、说不清的：齿隙、下垂、松动、发热 | 知道今天肩膀有点僵 |

### 4.2 三种节奏对应"苟日新，日日新，又日新"

| 原句 | 情况 | 更新什么 | 节奏 |
|---|---|---|---|
| 苟日新 | 突然的大变化（碰撞、换工具） | 几何参数，只改变了的那个 | 约 1 分钟，当场 |
| 日日新 | 缓慢的小变化（发热、松动、磨损） | 学习模型 | 每晚一次 |
| 又日新 | 见过的状态又出现 | 不重算，调出旧版本 | 几秒 |

固定顺序：**先查见没见过 → 再看几何能否解释 → 剩下的才交给学习模型**。否则学习模型会把一次大损伤当成"规律"硬学下来。

学习模型不实时更新是有意的：小变化单发看不出规律，要攒够数据；边干活边改易学进噪声。

### 4.3 若赛题的"模型"指大模型

可加一层放在**菜单外的伤**：大模型读残差分布和事件日志，提出"该放开哪些参数"的新假设，再由最小二乘拟合、护栏验证。大模型只提议，对错由数据裁决。代价是放弃全程离线，需备断网降级方案。（待确认赛题要求）

## 5. 为什么误差每台不同、且随使用变化

### 5.1 每台都不一样

| 来源 | 说明 |
|---|---|
| 齿轮间隙 | 每个舵机加工、装配公差不同 |
| 编码器 | 磁铁装偏造成的周期性误差，每颗不同 |
| 打印件 | 取决于打印机、料、摆放、填充 |
| 装配 | 舵盘 25 齿花键只能整齿装；螺丝松紧靠手感 |

场景：实验室 10 台同型号桌面臂，3 号上训的策略放到 7 号上抓取偏几毫米。工业臂同样需要逐台标定。

### 5.2 随使用变化

| 快慢 | 原因 | 场景 |
|---|---|---|
| 几小时 | 舵机发热、塑料变软；负载变化 | 冷机与连续运行后落点不同；换更重的夹爪 |
| 几天 | 螺丝振松；磕碰、搬动、拆装 | 教学场景每节课都在拆装 |
| 几周到几月 | 齿轮磨损（且随角度不均匀）；塑料蠕变 | 流水线重复同一动作几千次 |

诚实边界：逐日可见的主要是前两类；磨损要几周才看得出，比赛中只作为长期价值讲。演示可人为制造：加配重、松螺丝半圈、对比冷机与运行半小时后。

## 6. 监测逻辑

### 6.1 每一发的判断

1. 摄像头给出实际光点，减去自我模型的预测，得到残差。
2. 用学习模型给出的**不确定度**把残差归一化（建议用高斯过程，小数据也能给出不确定度）。
3. 两个检测器同时看：
   - 突变检测：连续 3 发远超正常范围。
   - 漂移检测：单发不超标但持续偏向一边（累积和 CUSUM / 指数加权移动平均）。

### 6.2 按残差形态分流

| 残差形态 | 判定 | 处理 |
|---|---|---|
| 单发很大，前后正常 | 光点识别出错 | 丢弃 |
| 突然变大，方向有规律 | 几何受伤 | 查版本库 → 诊断 → 校几何参数 |
| 小而持续累积 | 身体漂移 | 记入数据，夜里重训 |
| 落在没去过的姿势 | 没学过，不是异常 | 不报警，标记待采集 |

### 6.3 防误判规则

- 先问几何，再问学习模型。
- 学习模型修正量设上限（如几毫米），超出交回几何层。

### 6.4 学习模型对监测的贡献

1. 压低正常残差，阈值可以收紧（原文档建议 6 mm），能发现更小的异常。
2. 阈值因姿势而异：伸远的姿势本就不准，按不确定度归一化后两头都合适。
3. 区分"坏了"和"没学过"。

### 6.5 监测的前提与限制

监测依赖激光点落在靶板上。真实抓取任务中没有靶板，需要定期插入自检动作，或改为视觉直接跟踪末端。

## 7. 数据、标准值与检验

### 7.1 一条数据

| 字段 | 来源 | 角色 |
|---|---|---|
| 三个关节角度 | 舵机编码器 | 输入 |
| 各关节接近方向 | 前后两条指令之差 | 输入 |
| 负载、温度、电压 | 舵机回传 | 输入 |
| 光点实际位置 (x, y) mm | 摄像头 | **标准值** |

不需要额外的姿态传感器。

### 7.2 标准值从哪来

摄像头 + 靶板（四角定位码尺寸已知）就是那把尺子，独立于机械臂。训练目标自动产生，无需人工标注：

```
学习目标 = 摄像头量到的光点位置 − 几何公式算出的光点位置
```

模型做的是**回归**，不做好坏判断；判断由外部护栏按写死的规则完成。

### 7.3 检验必须用新数据

- 没见过的姿势：留出一部分姿势不参与训练。
- 之后的时间：用昨天数据训练，用今天开机自检的数据检验（最贴合"日日新"）。

通过标准：留出数据上"公式 + 学习模型"的误差明显小于"只用公式"，否则不上线。

### 7.4 限制

- 尺子本身要可信：用已知间距的点验证摄像头测距。
- 学不到重复精度以下。
- 只在光点落在靶板上的姿势范围内有效。

## 8. 完整逻辑一遍

1. **问题**：机械臂按自己对身体的了解计算关节角；身体变了而了解没跟上，就打偏。
2. **自我模型**：几何公式 + 学习模型。
3. **干活**：给定靶点，反解关节角，使预测光点等于靶点。
4. **发现过时**：每一发比较预测与摄像头实测，残差变大或持续偏向一边即过时。
5. **更新**：见过的直接调取；大变化当场改几何参数；小变化每晚重训学习模型。
6. **把关**：新版本须在没参与拟合的姿势上验证通过才采纳，否则保留旧版本；所有版本可回退。
7. **一天的循环**：开机自检 → 干活并记录 → 突变当场处理 → 夜里重训 → 次日用新版本开机。

> 一句话：机械臂持续用摄像头的观测检验它对自己身体的描述；描述过时了就更新——见过的直接调取，大的变化当场改几何参数，小的变化每晚重训学习模型，每次更新都要验证通过才生效。

## 9. 现场演示（约 6 分钟）

| 演示 | 评委看到 | 对应路线 |
|---|---|---|
| 评委"弄伤"机械臂（如关节错开一格） | 打偏 → 报出"J2 零点 +15°" → 校准后命中 | 苟日新 |
| 再制造同样的伤 | 认出旧伤，几秒恢复 | 又日新 |
| 版本曲线 | 每轮学习后误差下降，旁边是"只用公式"对照线 | 日日新 |

比赛只有 42 小时：把"采集 20 分钟 + 重训"当作一天，跑出三四个版本，并向评委明说是压缩周期。
