# ReArm 故障码说明

面板"诊断候选"表里的代码就是这里的故障码。注意：每次诊断会把 H1–H6 **全部**拟合一遍再排名，排第一的才是结论；其余行是被比下去的候选，不代表它们也坏了。

## 诊断候选（几何故障）

| 代码 | 名称 | 放开拟合的参数 | 物理含义 | 常见现象 |
|---|---|---|---|---|
| H1 | J1 零点偏移 | δ1 | 底座舵机的分度盘装错齿，整体偏航 | 落点绕底座整体转一个角度；通常是 15° 的整数倍（错 n 格） |
| H2 | J2 零点偏移 | δ2 | 大臂舵机分度盘装错齿 | 落点沿远近方向整体偏移，越远偏得越多 |
| H3 | 末端延长变化 | e | 激光前方加装或更换了延长杆 | 默认配置（激光与小臂同轴）下**无法从落点看出**，见"已知限制" |
| H4 | 底座位姿变化 | x_b, y_b, ψ_b | 底座被平移或转动 | 落点整体平移；纯转动与 H1 无法区分 |
| H5:Ha+Hb | 两组同时变化 | 两组参数的并集 | 同时发生两种伤，例如 H5:H1+H2 | 单一假设都解释不了；最终结论只报告精修后真正非零的那几组 |
| H6 | 全参数重标定 | 除基线后冻结的 L2 外全部 | 以上都解释不了时的兜底 | 结果多半会被护栏拒绝，需要人工检查机械结构 |

### 表中各列

| 列 | 含义 | 怎么看 |
|---|---|---|
| RMS / mm | 按该假设修正后，剩余落点误差的均方根 | 越小，说明该假设越能解释观测 |
| BIC | RMS 平方和 ÷ 测量噪声方差 + 参数个数 × ln(观测数) | 越小越可信；会惩罚"一次改很多参数"的假设 |
| ΔBIC | 与第一名的 BIC 差 | > 10 一般视为决定性；< 2 时两种解释几乎一样好，建议补打几发 |
| 修正 | 结论版本相对旧版本的参数变化 | δ 会吸附到 15° 整数倍，并换算为"格" |

## 自愈状态

| 状态 | 含义 |
|---|---|
| 正常 | 用当前版本打靶，持续监测误差 |
| 发现异常 | 连续 3 发误差中位数超过 6 mm，触发自愈 |
| 认旧状态 | 打 3 发固定探测，看是不是以前见过的伤；是则直接切回对应版本（秒愈） |
| 诊断 | 拟合 H1–H6 并主动选择最能区分前两名的姿势补打 |
| 校准 | 用最小二乘（Huber 损失、带边界和正则）求出新参数 |
| 护栏 | 在 4 个未参与拟合的姿势上验证新参数 |
| 已拒绝 | 新参数没通过护栏，保留旧版本，需要人工介入 |
| 重训残差 | 正在用打靶记录重新学习细节补偿 |
| 已急停 | 禁止动作与出光，多发流程在下一发前中止；确认安全并解除后才能重新操作 |

## 护栏拒绝原因

| 原文 | 含义 |
|---|---|
| holdout median exceeds 3 mm | 验证姿势上的误差中位数仍大于 3 mm |
| holdout improvement below 70 percent | 新版本比旧版本改善不足 70% |
| parameter bounds exceeded | 拟合出的参数超出物理范围 |
| missing observations or invalid holdout poses | 验证姿势打不到靶板或看不到光点 |
| optimizer failed | 优化器没有收敛 |

## 已知限制

- **H1 与 H4 中的底座转动不可区分**：两者只以 δ1 + ψ_b 的和出现。系统能恢复瞄准精度，但报告的伤类型可能是 H1。
- **H3 在默认配置下不可观测**：激光与小臂同轴时，延长杆只让出光点沿同一条射线移动，落点不变。需要给激光一个安装偏角，或增加其他观测手段。
