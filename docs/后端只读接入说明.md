# 后端只读接入（第一档）

目标：新控制台能**看到**真机后端（https://github.com/lizuyi-6/ReArm 的 `rearm/ui/server.py` 面板服务）的状态，能**急停**，但网页**不能让机械臂动**。生产、训练等运动指令属于第二档，后端正在制作，本档一律不接。

## 后端是什么样（以 245491f + R61 为准）

- 纯 HTTP，默认 `127.0.0.1:8080`，没有 WebSocket，没有 CORS 头。
- `GET /api/state`：全量状态 JSON，需要轮询。样本见 `tests/fixtures/backend_state_r61.json`（本机假机械臂实采 + R61 交接里的一次 `last_pick`）。
- `POST /api/cmd`，body `{"action": "...", ...}`；本档只用 `{"action":"estop"}`。
- `GET /api/camera/color.mjpg`、`/api/camera/depth.mjpg`：MJPEG；相机未启用时 503。
- `GET /api/vision/overlay.jpg`：最近一次识别的叠加图；未识别时 404。

## 架构

```
浏览器 console.html ──/backend/*──▶ 我们的 FastAPI（rearm/ui/server.py，--backend URL）──▶ 后端 8080
```

转发由我们的服务做，浏览器只访问同源，避开跨域。

### 转发白名单（安全边界，写死在服务端）

| 方法 | 我们的路径 | 转发到 |
|---|---|---|
| GET | `/backend/api/state` | `/api/state` |
| GET | `/backend/api/camera/color.mjpg` | 流式转发 |
| GET | `/backend/api/vision/overlay.jpg` | 原样转发 |
| POST | `/backend/api/cmd` | **只允许 `action == "estop"`**，其余一律 403「第一档只读：该指令未开放」 |

未传 `--backend` 时 `/backend/*` 全部 404。后端不可达时 state 返回 502 + 中文原因，不抛 500。

## 前端：后端数据源 `datasource/backend-source.js`

启用方式：`console.html?arm=backend`（缺省仍是本地演示）。对外接口与 `mock-console.js` 一致（subscribe / start / stop / send / commands），输出接口 v1 消息，store 和页面不用为它改分支。

| 后端字段 | v1 消息 / 页面 | 规则 |
|---|---|---|
| 轮询成功/失败 | `link` online/offline | 连续 3 次失败或 3 s 无响应判离线 |
| 首次成功 | `hello` | 数据来源写「后端面板」，带后端地址 |
| `telemetry.q_rad[0..5]`、`dq_rad_s` | `joint_state.q/dq` | `telemetry` 为 null 或 `stale` 时 valid=false，不填 0 |
| `telemetry.t_rotor_c`、`tau_nm` | temp、current | 原样，单位照抄后端 |
| J7（`q_rad[6]`）+ `gripper_refs` | `gripper_mm`、`gripper_valid`、`gripper_source` | 当次力矩标定换算；无参考、越界或过期时开口为 null |
| `enabled`、`connected`、`busy`、`busy_action`、`pose_error_deg` | 顶栏状态、设置页「连接」卡 | 已连接/未连接、已使能/未使能、忙（显示 busy_action） |
| `vision.last.detections` | `recognition.targets` | id 用 `part_id`（0 = 未知，名称「未知物体」），名称 `name`；**后端没有置信度**，confidence 给 null，页面不显示百分比；box_px 由 `center_px`、`long_mm/short_mm ÷ mm_per_px`、`angle_deg` 算外接框；图像尺寸取 `camera.color_intrinsics.width/height` |
| `last_pick` | 生产页「最近抓取」信息 | held → 夹到/未夹到；`reason`、`tip_errors_mm`（如 17.9 → 6.5 mm）、`retry_refused`。只显示，不计入完成套数 |
| `camera.enabled && fresh` | 观察画面 | 自动 `setCameraSource('/backend/api/camera/color.mjpg')`；否则「未接入摄像头」 |
| 急停按钮 | `POST /backend/api/cmd {action:"estop"}` | 成功后进入 estop 态；**解除急停只清前端横幅**，并提示「请在后端面板重新使能」——不能映射成 `enable`（可能自动回位） |
| 开始生产、训练、新增零件等 | — | `send` 直接拒绝，原因「第一档只读：生产指令由后端第二档提供」；对应按钮置为不可用并给提示 |

夹爪换算：`clamp(abs(q7 - touch) * mm_per_rad, 0, 110)`。`touch/open/mm_per_rad` 须为有限数、比例为正且两端不重合；q7 必须在两端各放宽 0.3 rad 的区间内，且遥测未过期。每帧仅用 `state.gripper_refs`，不复用历史标定或配置里的绝对零位。`gripper_source` 表示“当次力矩标定 / 未标定”，与 `gripper_valid` 分开；设置页显示来源，无效或离线时不显示数值。

零件库、配方、记录：后端没有，继续用本地演示数据，页面上标注「演示数据」。

## 验收

- 新增测试用 `tests/fixtures/backend_state_r61.json` 驱动，不依赖后端仓库。
- 服务端：白名单外的 action 被 403；未配 `--backend` 时 404；后端不可达 502。
- 前端：样本 → joint_state / recognition / last_pick 显示正确；stale 时 valid=false；非急停指令被拒绝。
- 本机联调：假机械臂后端（不连硬件）+ `?arm=backend`，孪生跟随摆动、观察画面显示假相机、识别标签出现、急停送达后端。
