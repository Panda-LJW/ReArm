# 控制台交互与动效优化清单

承接 [控制台视觉改版规范](控制台视觉改版规范.md)。本轮不改视觉风格，只解决“用起来顺不顺、反馈清不清楚、动效是否统一”。

## 0. 总原则

- 不改数据流、状态机、命令协议；`data-*`、`aria-*`、`role`、文案、测试选择器保留。
- 动效只表达状态变化和空间关系；时长用 `--t-fast/--t-base/--t-slow`，曲线用 `--ease-out/--ease-in-out`；`prefers-reduced-motion: reduce` 全部关闭。
- **一套动效系统**：所有通用动画只在 `modules/console/console.css` 定义一次，触发统一走 `modules/console/widgets/motion.js`。各页 css 里不再自定义进场、数值高亮、脉冲、角标、扫描线的 @keyframes（审查发现生产、零件库、记录、设置各写了一份，与 console.css 重复）。

## 1. 共享动效接口（固定，页面直接用）

| 名称 | 写法 | 效果 |
|---|---|---|
| 进场错峰 | `stagger(cards)` 或元素加 `.c-enter` + `style="--i:n"` | 淡入并上移 6px，`--t-slow`，每级 40ms，最多 6 级 |
| 数值高亮 | `flash(el, value)` | 值变化时文字 `--sub→--data` + 底部 1px 线左扫右；首次赋值不闪 |
| 内容交叉淡入 | `await swap(el, () => 替换内容)` | 旧内容 120ms 淡出，替换后淡入 |
| 一次性重播 | `replay(el, className)` | 移除、回流、加回，`animationend` 自动移除 |
| 运行脉冲 | `.c-pulse` | opacity 1↔.25，1s |
| 画面运行态 | `.c-viewport[data-busy="true"]` | 顶边 1px 扫描线循环 |

console.css 需提供：`.c-enter`、`.c-flash`、`.c-swap-out`、`.c-swap-in`、`.c-pulse`、`.c-viewport[data-busy]`、`.c-focus-row`、`.c-toast`、`.c-progress`。

## 2. 外壳与全局

1. **急停横幅**：不再把页面往下推（改为覆盖在顶栏下方、内容区上方，页面预留固定高度或用 overlay 不引起布局跳动）；横幅内加「解除急停」按钮，复用现有 `createReset` 流程（仿真直接重置、真机弹确认）；按钮在原流程未退出前保持现有禁用规则。
2. **页面切换**：内容区在切页时做 160ms 交叉淡入（支持 View Transitions API 时用 `document.startViewTransition`，否则用 `.c-swap-*`）；导航底线滑动保留。
3. **命令反馈 toast**：`ctx.send` 返回 `ok:false` 或抛错时，在右下角弹出 `.c-toast`（3 秒自动消失、可关闭、`role="status"`、同类消息合并）。已有用对话框提示的错误（如重置失败）保持对话框，不重复弹 toast。
4. **按钮忙碌态**：发出命令到收到回复之间，按钮加 `aria-busy="true"`、显示细进度条或省略号，防止重复点击；回复后恢复。提供通用工具（如 `widgets/busy.js` 的 `withBusy(button, promise)`）。
5. **键盘**：`Alt+1..4` 切换四个页面；所有可交互元素有统一的 `:focus-visible` 样式（2px `--focus` 外框，表格行用 `.c-focus-row` 左侧线 + 外框）；对话框打开时焦点落在第一个可操作控件，关闭后回到触发按钮。急停不设快捷键（避免误触）。

## 3. 生产页

1. **缺陷**：急停或无运行时步骤列表丢失抓取/放置步骤、右上 chip 显示「—」。`steps.js` 与 `stage-chips.js` 的配方解析不一致（一个只查 `recipeDocs`，一个回退到 `library.recipes`；`state.run` 存在但 `recipe_id` 缺失时取到空）。统一为一个选择器：有运行且有 `recipe_id` 用运行的配方，否则用当前选择；`recipeDocs` 缺失时回退 `library.recipes`。
2. 当前步骤自动滚入可视区（`scrollIntoView({block:"nearest", behavior:"smooth"})`，减少动效时 `auto`）。
3. 步骤卡标题右侧显示进度 `x / N`，标题下方一条 2px `.c-progress` 进度条随步骤推进平滑增长。
4. 开始确认框：勾选框获得初始焦点；勾选后回车即确认。
5. 一套完成时：KPI 用 `flash`；画面右下 chip 短暂显示「完成 ✓」再回到常态。
6. 画面 `data-busy` 跟随运行状态；把页面内重复的扫描线、角标、脉冲、进场动画换成共享实现并删除 production-motion.css 中的重复 @keyframes。

## 4. 零件库页

1. 列表行：统一焦点样式；`↑/↓` 移动选中并聚焦，`Home/End` 跳首尾，`Enter` 打开；选中行保持在可视区。
2. 详情切换用 `swap`；偏差曲线首次出现时折线从左到右绘出（stroke-dashoffset，`--t-slow`）。
3. 零件/配方分段切换底线滑动（与导航一致）。
4. **新增流程**：第 1 步当前只有一个按钮、下方大片空白。加入：步骤说明（这一步会做什么、需要准备什么）、`.c-viewport` 预览区（复用观察画面的示意/摄像头口，没有数据时显示“等待拍照”）、底部操作栏固定（上一步 / 下一步 / 取消）。步骤之间内容 `swap`，步骤条之间的连接线随进度填充。
5. 页面专属的重复 @keyframes 删除，改用共享实现。

## 5. 记录页与设置页

1. 表头可点击排序（时间、偏差、用时、轮数），`aria-sort` 标注，排序切换时行交叉淡入；默认时间倒序（与现状一致）。
2. 表头吸顶；表格行 hover 背景过渡。
3. KPI 用 `flash`；空状态加一行说明“完成一次生产后这里会出现记录”。
4. 设置页：数值可选中复制；连接状态变化时圆点颜色过渡并 `flash`。
5. 删除页面专属的重复 @keyframes。

## 6. 验收

- `.venv/bin/pytest -q tests/` 全绿；新增交互要有测试（排序、方向键、toast、busy、配方解析缺陷回归）。
- 逐帧截图核对：切页 0/80/160/320ms、急停横幅出现与解除、新增流程三步、步骤推进。
- 减少动态效果下无任何动画、功能不受影响。
