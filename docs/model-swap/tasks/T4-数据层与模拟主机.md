## 消息与指令（接口 v1）
主机 → 面板，每条 `{ v:1, type, seq, t }`，`t` 为 Unix 毫秒：

| type | 主要字段 |
|---|---|
| `hello` | `proto`、`host_version`、`arm:{model, joints}`、`threshold_mm`、`camera:{url, format}`、`sim`、`laser_ttl_ms`、`node_timeout_ms` |
| `joint_state` | `mode`(`idle`/`demo`/`practice`/`estop`/`fault`)、`q`[6]、`dq`[6]、`current`[6]、`temp`[6]、`valid`[6]、`gripper_mm`、`gripper_valid`、`pass`、`node`、`settled`、`fault` |
| `demo_trajectory` | `demo_id`、`samples:[{t,q,gripper_mm}]`、`nodes:[{id,t,q,gripper_mm,gripper_state,ref_spot_base_mm,ref_spot_px,end_base_mm?}]` |
| `node_result` | `pass`、`node`、`spot_px`、`depth_mm`、`spot_base_mm`、`ref_spot_base_mm`、`dev_mm`[3]、`dev_norm_mm`、`valid`、`invalid_reason`、`image_url`、`end_base_mm` |
| `pass_result` | `pass`、`max_mm`、`mean_mm`、`valid_nodes`、`total_nodes`、`below_threshold` |
| `correction` | `pass`、`applied`、`items:[{target,delta,unit,note}]`、`llm_text` |
| `laser_state` | `on`、`source`(`sensed`/`software`)、`remaining_ms`、`reason` |
| `event` | `name`、`text`、`level` |
| `heartbeat`、`error` | `error` 带 `code`、`msg` |

面板 → 主机：`POST {base}/api/v1/command`，体 `{ v:1, cmd, seq, t, ...参数 }`，应答 `{ v:1, ok, code, msg, seq }`。`cmd`：`demo_start`、`demo_stop`、`practice_start`、`practice_stop`、`estop`、`reset_estop`、`mark_node`、`laser_on {ttl_ms}`、`laser_renew {ttl_ms}`、`laser_off`。

## 要做的文件
1. `modules/datasource/host-source.js`：真主机。`createHostSource({ url, WebSocketImpl, fetchImpl, offlineAfterMs = 3000, retryMs = 1000 })` → `{ kind:"host", start(), stop(), subscribe(cb), send(cmd, args) }`。
   - `subscribe` 的回调收到原始消息对象；连接状态用 `{ type:"link", online:boolean, reason }` 通知（首次连上、断开、超过 `offlineAfterMs` 没收到任何消息都要通知）。
   - `send` 用 `fetchImpl` POST 到由 ws 地址推出的 http 基址（`ws`→`http`、`wss`→`https`，同主机同端口，路径固定 `/api/v1/command`）；返回应答对象；网络失败返回 `{ ok:false, code:"network", msg }`，不抛异常。自增 `seq`。
   - `v !== 1` 或不是对象的消息丢弃。断线后按 `retryMs` 重连。**不回退到模拟数据。**
   - 导出纯函数 `commandUrl(wsUrl)`。
2. `modules/datasource/mock-host.js`：浏览器内的模拟主机，接口与 host-source 完全相同（`kind:"mock"`），所有 `hello` 带 `sim:true`。
   - 可注入时钟：`createMockHost({ now = Date.now, setTimer = setInterval, clearTimer = clearInterval, rateHz = 20, seed = 1 })`，并提供 `advance(ms)`（测试用：不靠真实定时器，按给定毫秒推进内部状态并发出该发的消息）。
   - 行为：启动后 `mode: idle`，持续发 `joint_state` 和 `heartbeat`。
     - `demo_start` → `mode: demo`，关节沿一条写死的平滑“抓取”轨迹走（6 轴都要动，全部在 `ARM_PARAMS` 限位内，时长约 6 s，夹爪中途闭合）；`demo_stop`（或走完）→ 回到 `idle` 并发一条 `demo_trajectory`（样本即刚才发过的关节数据；自动分 4 个节点，`ref_spot_base_mm` 用 `laserRay` 沿光束 0.25 m 处的点）。
     - `practice_start`（必须已有示范，否则应答 `ok:false`）→ `mode: practice`，反复重放示范轨迹；每一遍给关节加一个随遍数衰减的偏差，使节点偏差大致为 `18 · 0.62^(pass-1) + 小噪声` mm，降到约 2–3 mm 后稳定（确定性伪随机，同一 `seed` 结果相同）。到每个节点：停住约 0.8 s，先发 `settled:true` 的 `joint_state`；**只有激光此时是开的**才在约 0.4 s 后发 `valid:true` 的 `node_result`，否则在 `node_timeout_ms` 后发 `valid:false, invalid_reason:"spot_not_found"`。一遍结束发 `pass_result` 和一条 `correction`（`llm_text` 是一两句中文说明，如“第 3 遍在节点 2 偏右 4.1 mm，已把 J1 目标角减小 0.6°。”），再发 `event`。`practice_stop` → `idle`。
     - 激光：`laser_on {ttl_ms}` 开并记到期时间；`laser_renew` 顺延；`laser_off` 关；到期没续期自行关（`reason:"ttl_expired"`）；每次变化发 `laser_state`（`source:"software"`），并每秒发一次带 `remaining_ms` 的状态。
     - `estop` → `mode: estop`、停止运动、激光关（`reason:"estop"`）、之后除 `reset_estop` 外的指令应答 `ok:false, code:"estop"`；`reset_estop` → `idle`。
     - 示范与练习互斥：进行中收到另一个的开始指令应答 `ok:false, code:"busy"`。
   - 记录收到的全部指令：`commands()` 返回数组（测试用）。
3. `modules/trainer/config.js`：`{ thresholdMm:5, laserTtlMs:3000, laserRenewMs:1000, nodeTimeoutMs:2000, offlineAfterMs:3000 }`。
4. `modules/trainer/store.js`：纯函数 `initialState()`、`reduce(state, message)`（不修改入参，返回新状态）。状态至少含：`link:{online}`、`hello`、`mode`、`joint`（最新 `joint_state`）、`demo`（最新 `demo_trajectory`）、`passes`（数组：每遍 `{pass, nodes:{id→node_result}, result, correction}`）、`laser`（最新 `laser_state`）、`laserCommand`（面板最近一次激光指令的期望值，由 `{type:"panel_laser", want:boolean, t}` 这种面板内部消息更新）、`events`（最多 100 条）、`currentNode`。断线（`link.online=false`）时 `mode` 保留但另有 `stale:true`。
5. `modules/trainer/metrics.js`：纯函数 `summarize(state, config)` → `{ pass, lastMeanMm, lastMaxMm, firstMeanMm, improvedPct, corrections, belowThreshold, laserMismatch }`。没有数据的项是 `null`。`improvedPct = (first − last) / first × 100`。`laserMismatch`：面板期望与主机回报不一致且已超过 1 s。
6. `modules/trainer/laser-guard.js`：`createLaserGuard({ send, now, setTimer, clearTimer, config })` → `{ onMessage(message), manual(on), shutdown(reason), state() }`。规则：
   - 练习中（`mode === "practice"`）收到 `settled:true` 且该 `(pass,node)` 还没测过 → 发 `laser_on {ttl_ms}`；之后每 `laserRenewMs` 发 `laser_renew`；收到同一 `(pass,node)` 的 `node_result` 或等满 `nodeTimeoutMs` → 发 `laser_off`。
   - `manual(true/false)`：只在非练习、非急停、在线时允许，开着时同样续期；练习开始时若手动开着先关掉。
   - 以下任一发生立即发 `laser_off` 并停止续期：`mode` 变为 `estop` 或 `fault`、`{type:"link", online:false}`、`shutdown("pagehide"|"hidden"|"route"|"estop_click")`。断线时也要尝试发一次（发不出去不抛异常）。
   - 不重复刷指令：已经是关且没有待续期时，`shutdown` 仍发一次 `laser_off`（安全兜底宁多勿少），但连续调用间隔小于 200 ms 的合并为一次。
   - `state()` → `{ want, auto, manual, activeNode }`。
7. `modules/datasource/index.js`：`SOURCES` 增加 `host`、`mock`；新增 `trainerSourceFromParams(params)`：有 `backend` 参数（必须是 `ws://` 或 `wss://`，否则抛错）→ host；没有 → mock。原有的 `sourceFromParams` 行为不变。
