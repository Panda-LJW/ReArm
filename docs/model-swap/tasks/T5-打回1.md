截图在 1920×1080 与 1280×720、日常与路演模式下看到以下问题，**全部要改**：

1. **“比第一遍好了多少”显示成 `−86 %`**。标题问的是“好了多少”，带负号读起来像变差了。改为：数值 `86`、单位 `%`，副行 `↓ 18.0 → 2.6 mm`；变差时数值写 `12`、副行 `▲ 变差 · 18.0 → 20.2 mm` 并用 `--bad` 色；只有第 1 遍时数值 `—`、副行“第 1 遍是基准”。不要出现 `−0%`。
2. **单位和负号**：修正项和摘要里出现 `deg` 和 ASCII 的 `-0.00`。角度一律显示 `°`，负号用 `−`（U+2212），四舍五入后为 0 的不带符号（显示 `0.00°`）。mock-host 的 `unit` 仍可以是 `deg`（接口里的单位名），但面板显示时要换成 `°`；mock 的 `llm_text` 也用 `°` 和 `−`，并避免出现 `−0.00`。
3. **修正项列表四行都是“J1”**，看不出区别。每行写成“J1 · 节点 2”（`target` + `note` 里的节点信息；`note` 为空时只写 `target`）。
4. **数字孪生里“偏差 2.6 mm”标签盖住了左上角的“模拟数据”状态芯片**；路演 1280×720 下节点编号标签和 J4 关节标签挤在一起。要求：孪生的所有浮动标签不得进入状态芯片所在的区域（左上角，按芯片实际尺寸加 8 px 留白）；节点编号标签与关节标签重叠时，节点编号让位（隐藏或偏移），偏差标签优先级最高。用 `getBoundingClientRect` 做一次简单的避让即可，写在 `modules/twin/twin.js`，加测试（文本检查有避让逻辑即可）。
5. **路演 1920×1080 下“最近事件”卡片被挤得只剩标题（47 px 高）**，关节卡片 7 行占满了。路演模式下关节卡片一律用两列排布（1280×720 路演时已经是两列，效果可以），这样 1920 下事件卡片能露出至少 3 条。
6. **路演 1280×720 下关节卡片底部的“最高温度 / 最大电流 / 模式”一行被裁掉约 11 px**。压缩行距或把这一行并到两列网格里，保证不截断。
7. **手眼相机画面里的光点位置不合理**：模拟画面上光点画在右上角，路演 1280 下被“激光”芯片盖住。相机和激光平行安装、激光在相机正下方约 20 mm，所以光点在画面里应该在**画面中心略偏下**，偏差只让它小幅偏离。改 mock-host 的像素计算：用针孔模型把光点从相机坐标投影到画面（焦距按 `hello.camera` 里的分辨率和 87°×58° 视场角算，分辨率默认 640×480），示范光点和实测光点都这样算。`camera.js` 画的时候也要保证光点和标签不落在四个角的芯片下面（落进去就把标签挪到光点另一侧）。
8. **相机画面上 SVG 里的文字太小**（1920 日常模式下量到 8 px）。SVG 的 `viewBox` 会缩放文字：标签改用 HTML 浮层，或者按画面缩放比例反算字号，保证屏幕上不小于 `--fs-sm`，路演模式下不小于 18 px。
