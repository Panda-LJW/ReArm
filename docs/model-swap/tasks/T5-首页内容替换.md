## 1. `app.js` 的认领接缝（只加这个，别的不动）
- 加 `const claimed=region=>(document.documentElement.dataset.claim||"").split(" ").includes(region);`
- `render()` 里写 `kpis`、`joints`、`feed`、`errchart`、`diag`、`cam` 这些区域的语句，各自包在 `if(!claimed("区域"))` 里；`refreshCamera()` 在 `claimed("cam")` 时直接返回（并 `stopCamera()`）；`syncControls()` 照常（急停按钮不受影响）。`actions` 区域由 trainer 自己隐藏旧按钮，`app.js` 不用管。
- 没被认领时行为与现在逐字节一致。`?legacy=1` 下旧首页和全部旧测试必须照常。

## 2. `modules/main.js`
- 非 `?legacy=1` 时加载 `trainer/trainer.js` + `trainer/trainer.css`（放在 twin 之后）；`?legacy=1` 时不加载 trainer。
- 非 legacy 时不加载 `guide`（它讲的是旧流程）。
- 非 legacy 时孪生不再接 `sourceFromParams` 的旧数据源，改由 trainer 喂：把 `twin` 对象交给 `initTrainer({ twin, params })`（twin 模块没加载成功时传 `null`，trainer 照常工作）。legacy 时保持现在的接法。
- trainer 加载失败：清掉 `dataset.claim`，页面退回旧版内容（并让 `app.js` 重画一次：派发 `rearm:theme` 或 `rearm:modules-ready` 即可）。

## 3. `modules/trainer/trainer.js` 与 `views/`
`initTrainer({ twin, params })`：
1. `document.documentElement.dataset.claim = "kpis joints feed errchart diag cam actions"`，`dataset.trainer = "on"`。
2. `trainerSourceFromParams(params)` 建数据源；建 `laser-guard`（`send` 指向数据源）；订阅消息 → `reduce` → 各 view 渲染（用 `requestAnimationFrame` 合并，一帧最多渲染一次）。
3. 把关节帧喂给孪生：`twin.update(makeFrame({ q_rad, valid, gripper_mm, mode, laser, timestamp }))`，其中 `mode` 映射为孪生的 `sim`（`hello.sim` 为真）/ `live` / `offline`（断线）；轨迹与光点通过 `twin.setOverlay(...)`：`demoPath` 用 `buildPath(ARM_PARAMS, demo.samples)`；`runPath` 用本遍已收到的关节帧（trainer 自己按 `pass` 累积原始 `joint_state`，换遍时清空）；`nodes` 用示范节点的 tcp 位置，当前节点高亮；`spots` 用最近一条有效 `node_result`（mm→m）。
4. 页面生命周期：`pagehide`、`visibilitychange` 变 hidden、`hashchange` 离开主页 → `laserGuard.shutdown(...)`；急停按钮 `#estop` 被点击（捕获阶段监听，不阻止原行为）→ 向数据源发 `estop` 并 `laserGuard.shutdown("estop_click")`；`#resetstop` 确认解除后（监听 `rearm:state` 里 `state.estop` 由真变假）→ 发 `reset_estop`。
5. 断线（`link.online=false`）或还没收到 `hello`：所有 trainer 按钮禁用，各区域显示“离线”，孪生离线。
