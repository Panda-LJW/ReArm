# 遥控面板方案（只写方案，这一轮不写代码）

用途：用操控器让机械臂做基本动作，辅助调整——上下移动、夹爪开合、摆头（腕偏摆）、旋转（腕旋转 / 底座转）。后端还没定，接口是建议稿。

## 1. 放在页面哪里

| 方案 | 做法 | 优点 | 缺点 |
|---|---|---|---|
| A. 可拖动的浮窗（推荐） | 顶栏“⋯”里加“遥控…”，打开一个和现在“仿真调试”一样的可拖动小窗，默认停在数字孪生卡片下沿 | 不占首页版面，不动布局；边看孪生和相机边操作；路演时不打开就完全不出现 | 小窗里按钮不能太多 |
| B. 单独一页 | 导航加第四项“遥控”，整页放大号按钮、孪生和相机画面 | 空间充足，适合平板触控 | 要改导航结构；离开主页看不到偏差数据 |
| C. 放进关节卡片 | 每个关节一行加“− / +”按钮 | 和读数对得最直接 | 关节卡片已经放了 6 行加夹爪，再加按钮会挤，路演模式下尤其放不下 |

推荐 A。它复用现有浮窗的拖动和样式，是一个新的可选模块（`modules/teleop/`），删掉不影响别的；也不需要你现在就决定导航怎么改。B 可以等确定要用平板操作时再做。

## 2. 小窗里放什么

- **模式切换**：末端模式（默认）／关节模式。
- **末端模式**：上、下、前、后、左、右六个方向键（基座系，每次按住匀速移动）；摆头左／右（J5）；旋转左／右（J6）；夹爪开／合。
- **关节模式**：J1–J6 各一对“− / +”。
- **速度档**：慢（默认）／中，两档。不提供“快”。
- **状态行**：当前模式、是否正在运动、最近一次被拒绝的原因。
- 键盘：方向键对应前后左右，`PageUp/PageDown` 对应上下，其余不设快捷键，避免误触。只有小窗获得焦点时键盘才生效。
- 手柄：以后要接手柄时，用浏览器的 Gamepad 接口读摇杆，换算成同一套指令；面板不直接碰 USB。

## 3. 需要的接口（建议稿，加进 `docs/接口文档.md` 的下一个小版本）

指令（面板 → 主机，仍走 `POST /api/v1/command`）：

| cmd | 参数 | 说明 |
|---|---|---|
| `jog_start` | `space`：`"base"` 或 `"joint"`；`axis`：`"x"/"y"/"z"/"j1"…"j6"/"gripper"`；`dir`：`1` 或 `-1`；`speed`：`"slow"` 或 `"medium"`；`ttl_ms` | 开始朝一个方向匀速运动。带有效时长，和激光一样要续期 |
| `jog_renew` | `ttl_ms` | 续期。按住期间面板每 200 ms 发一次 |
| `jog_stop` | 无 | 立即停。松手、失焦、切页面、断线、急停时面板都发 |

状态（主机 → 面板）：在 `joint_state` 里加 `mode: "teleop"` 和 `jog: { active, space, axis, dir, limited }`；被限位或工作空间挡住时 `limited: true`，面板显示“已到限位”。

主机侧必须保证：

- 收不到续期（建议有效时长 400 ms）就自己停，不依赖面板的 `jog_stop`。
- 关节限位、速度上限、工作空间边界、碰撞由主机判断，面板只显示结果。
- 示范中、练习中、急停、故障时拒绝遥控指令。

## 4. 安全上要注意什么

1. **按住才动，松手即停**：按钮用 `pointerdown` 开始、`pointerup / pointercancel / pointerleave` 停止，不做“点一下走一步再点一下停”。
2. **断线即停**：面板断线时本地立刻把所有按钮恢复成未按下，主机因收不到续期在 400 ms 内自行停。
3. **互斥**：遥控和示范、练习互斥。小窗打开期间“示范”“练习”禁用，反过来也一样。
4. **急停优先**：急停按钮始终可点；小窗永远不能盖住急停按钮（限制拖动范围，顶栏区域不可进入）。
5. **激光**：遥控时激光默认关。要开只能用现有的手动激光开关，规则不变。
6. **窗口失焦、切到别的标签页、切页面**：等同松手，立即发 `jog_stop`。
7. **速度**：默认慢档，每次打开小窗都回到慢档，不记忆上次的选择。
8. **第一次使用的提示**：打开小窗时显示一行“按住移动，松开即停；周围不要站人”，可以关掉，但每次页面加载后第一次打开都会再出现。
9. **只在接真机时显示告警色**：模拟数据下小窗标题写“遥控（模拟）”。
