# ReArm 上位机 v0

3 自由度激光打靶机械臂的本地上位机：预测落点、发现模型失效、识别旧状态、诊断并校准几何、保存可回退版本，再用 GP 学习小幅非几何误差。

唯一需求来源是 [目标文档](docs/ReArm_上位机_goal.md)。实现和实测结果分开记录；第 7 节验收标准保持原值。最终数字见 [仿真实测报告](reports/eval_sim_report.md)。下述能力为仿真及单元测试验证结果，用户侧使用验收待验证。

## 运行

从本仓库根运行，使用已准备好的 Python 3.11 环境，不需要联网安装：

```sh
.venv/bin/python scripts/build_pose_pool.py
.venv/bin/python scripts/demo.py --sim
.venv/bin/python scripts/collect.py --sim --shots 300 --nongeometric
.venv/bin/python scripts/train_residual.py
.venv/bin/python -m rearm.ui.server --sim --nongeometric
.venv/bin/pytest -q
.venv/bin/python scripts/eval_sim.py
```

面板地址为 `http://127.0.0.1:8000`，分三页：

- **主页**：俯拍摄像头画面（叠加预测落点、实测落点和近期落点，状态与误差悬浮在画面四角）；瞄准误差、细节补偿收益、累计打靶、自愈次数；关节读数与限位；最近事件；瞄准误差曲线（对数刻度，鼠标悬停可看每一发）、诊断候选表（结论只突出主要修正，其余微调可展开；故障码、放开参数、RMS、BIC、ΔBIC）、学习效果曲线。屏幕高度不超过 800 像素时，最近事件并入诊断候选卡片，用标签切换。
- **数据总览**：自愈成功、平均恢复发数、最佳精度等汇总；历次自愈记录表（时间、结果、诊断结论、用了几发、自愈前后误差、启用版本）；各故障码次数和每次自愈用的发数。
- **故障码**：渲染 `docs/故障码.md`。

顶栏的“自我模型”下拉框列出所有版本。切换版本分三步：查看与当前版本的参数差异 → 预检（用该版本试打 3 发，与当前版本对比）→ 输入版本号确认。预检未通过时需勾选强制切换；切换后 30 秒内可撤销。远程命令接口不再提供不经预检的回退。仿真伤注入在“⋯ → 仿真调试”里。

第二、三批面板已于 2026-11-13 由验收方用无头 Chromium 实测通过：桌面 1280×720、1366×768、1440×900、1920×1080 和手机视口 390×844 的排版，以及键盘操作、焦点保留、hash 路由、确认框、调试窗拖动、急停、解除急停、流程中急停、MJPEG、断线重连。具体功能如下：

- 页面地址分别为 `/#home`、`/#overview`、`/#codes`，支持刷新和前进后退。版本详情只在相关数据变化时重建，保留输入、勾选和光标；自愈发数由后端 `heal_start` 计算，中途刷新可恢复。
- WebSocket 断开后显示“数据已过期”，摄像头状态为“连接断开”，所有命令按钮禁用；按 0.5、1、2、4、8、10 秒退避重连，收到新快照后恢复。首次状态读取失败也会显示提示。
- “首次标定”“重训补偿”先确认再执行，说明试打数量和新版本产生条件。执行中显示对应进度文案；已知错误与护栏原因使用中文，未知错误附中文前缀。仿真调试窗默认覆盖摄像头左下区域，可拖动标题移动并限制在视口内。
- 顶栏最右侧“急停”在操作进行中仍可使用。急停立即置位独立信号并请求关闭激光，多发流程在下一发前中止；急停期间禁止自检、标定、重训、预检、切换和注入。红色“已急停”横幅提供需确认的解除按钮；原流程退出前不能解除，解除后不会自动续跑。
- 摄像头显示“激光 开/关”，表示驱动调用后的软件状态；关闭失败时保留上次状态并提示检查硬件。仿真仍每发刷新 `/api/camera.jpg`；非仿真快照使用 `/api/camera.mjpg`，接入 `FrameSource` 后约 5 帧/秒，断开后结束流并等待当前读帧结束，不保留后台采集任务。
- 版本和“⋯”菜单支持 Tab、方向键、Enter、空格；Esc 关闭并把焦点还给触发按钮。对话框内循环 Tab；导航、菜单和三张图表提供无障碍状态或文字摘要。手机顶栏设为两行，第二行为导航；保留桌面一屏布局与矮屏事件标签。

软件急停不替代实体急停：当前硬件接口没有运动制动方法，已下发运动的立即制动、激光物理关断和真实相机仍需真机验收。`build_app(sim=False)` 仍保留原有的驱动未实现提示。

完整评估每类伤运行 100 次，总计 800 次，另测基线、误报、松动拒绝、GP、回退和 pytest。只要有一项未通过就返回退出码 `1`，同时照常保存报告；这不表示脚本没有完成。`--trials` 和 `--skip-pytest` 只用于调试，不可把缩减样本称为完整验收。

依赖仅使用 numpy、scipy、scikit-learn、opencv-contrib-python、pyserial、fastapi、uvicorn、pydantic、pyyaml、pytest 及标准库。没有大模型调用、外部字体、CDN、在线资源或安装步骤。

## 配置

| 文件 | 内容 |
|---|---|
| `config/arm_nominal.yaml` | 12 个几何参数、边界、关节限位、靶面尺寸和向下光轴约束 |
| `config/thresholds.yaml` | 检测、BIC 拟合、护栏、GP、IK、姿势池、验收样本与阈值 |
| `config/sim.yaml` | 固定种子、测量噪声、齿隙、负载下垂、每发热增量、伤幅度 |
| `config/camera.yaml` | ArUco 四角、相机内参/畸变、激光与圆贴纸检测阈值 |

关节角为度，落点为靶板坐标系毫米；x 沿长边向右，y 远离机械臂，z 向上。偏航为 `q1 + delta1 + psi_b`。激光方向采用径向、水平切向和竖直分解，`gamma` 为偏离竖直运动平面的小偏角。只有向下分量满足要求、出光点在板面上方、落点在板内且关节限位合法时才有效。

仿真噪声可设为零，非几何误差可整体关闭；齿隙、下垂、热漂各自系数也可设为零。温升按发次推进模拟运行时间，复现实验无需真实等待。

## 模块关系与替换

```text
scripts / UI CLI → app.py（组装）→ evo/controller.py（编排）
                                    │
                 ┌──────────────────┼──────────────────┐
                 ▼                  ▼                  ▼
           ArmIO / Shooter      几何与诊断接口       版本 / 日志 / 事件总线
           sim 或 hw           model/evo/residual      │
                 │                  │                  ▼
                 └──── Shot ────────┘              UI 订阅事件

跨模块数据：types.py；可替换组件：interfaces.py
```

| 模块 | 职责与替换点 |
|---|---|
| `types.py` / `interfaces.py` | 统一数据类型和 Protocol；算法之间不导入其他实现 |
| `config.py` | 一次读取并校验 YAML，将配置通过构造器注入 |
| `model/` | 射线与靶面交点、数值雅可比、带限位 IK、自我模型、有效姿势池 |
| `sim/` | ArmIO 仿真、独立真实参数、伤注入、合成摄像头 |
| `vision/` | 四角 ArUco 单应、去畸变、激光开关差分质心、圆贴纸靶点 |
| `evo/` | 滑窗异常、3 发认旧、BIC 假设竞争、主动选点、Huber 校准、四发护栏、版本库 |
| `residual/` | ZeroResidual/GPResidual、异常数据剔除、按时间留出训练和上线判定 |
| `task/` | 下发姿势、读取遥测、开激光测量、finally 关激光 |
| `logging/` | 每发 JSONL、事件 JSONL、进程内订阅总线 |
| `ui/` | FastAPI/WebSocket 和原生单页，订阅事件展示、通过命令接口操作 |
| `hw/` | 与仿真同签名的真机骨架；未确认协议的操作直接抛异常 |

新几何或残差算法实现对应 Protocol 后，在 `app.py` 替换构造器即可；`controller.py` 仅编排。算法不操作硬件、文件或 UI；残差接口要求的 `save/load` 是显式持久化边界。UI CLI 只把组装转交 `app.py`。

## 自愈流程

1. 连续窗口满 3 发且残差中位数超过 6 mm 后报警；单发离群不触发，异常首发也从训练数据剔除。
2. 用固定 3 发与已采纳版本比较；最小 RMS <3 mm 且小于第二名一半时切换。
3. 否则拟合 H1/H2/H3/H4、任意两组 H5、全参数 H6，先用连续拟合的 BIC 排名，再对选中模型整格吸附；后续 3 发主动选前两名预测差异最大的姿势。BIC 使用同一配置测量标准差，计算 `SSE/σ² + k·log(n)`，不让各假设分别缩小噪声方差。诊断结论只报告最终精修后仍变化的参数组，原始假设得分完整保留。
4. 用有边界、向旧版本正则的 Huber 最小二乘校准；大角度提供 0°、±15°、±30° 起点，已经到达配置噪声容差时停止多余重启；接近整格时吸附后精修。
5. 在预留的 4 个姿势上验证，要求中位数 ≤3 mm、相对旧版本下降 ≥70%、参数合法；拒绝候选时保留原 HEAD。
6. 几何改变后新版本使用 ZeroResidual，旧 GP 留在旧版本中。状态正常时才能手动重训，按时间保留最近 25% 数据；新模型留出中位误差严格低于当前模型才上线。

默认新伤恢复使用报警后的 20 发，其中识旧 3 发计入 13 发初始诊断，再加 3 发主动选点与 4 发护栏；四发护栏与拟合、主动选点完全分离。异常期、失去光点、诊断与护栏数据不进入 GP；GP 输出二维标准差，并将修正向量长度限制在 5 mm。

名义无伤状态已经很准时，基线拟合可能无法再降低 70%，候选会被拒绝而原版本继续使用，这是护栏的正常行为。正式基线验收另外注入隐藏装配偏差，验证全参数校准和 20 个随机靶点。

## 数据与回退

`runtime/` 默认保存 `shots.jsonl`、`events.jsonl`、`versions/vNNNN.json`、`versions/HEAD` 和 `residuals/rNNNN.npz`。每发记录时间、q、接近方向、负载、温度、电压、预测、实测、残差、GP 不确定度、版本、异常标记及用途。失去光点记录 `null`，不伪造坐标。

几何与残差分别编号。回退可选择完整版本、仅几何或仅残差；分层回退会生成组合版本并记录来源，拒绝版本不能启用。GP 保存训练数组和固定超参数，加载不执行 pickle；回退预测按相同姿势和特征验证一致性。

评估的逐次记录、聚合 JSON、pytest 原始输出和 JUnit 位于 `reports/`；报告中的 `runtime_evidence` 指向该次试验的完整发次日志与版本。评估器允许用仿真真值做额外独立审计，诊断和校准不读取伤标签或真值。

## 已知缺口

最终完整评估运行 255.27 秒，共 800 次伤试验；pytest 39 项全过。基线 20/20 命中、无伤 100 发报警 0 次、采纳更差版本 0 次。J1/J2 类型与格数准确率为 99%/98%，底座 x/y 平移均为 100%。

| 未达标项 | 实测与原因 |
|---|---|
| 发现 | 延长 +20/+40 mm 各 0/100 次报警；名义光轴下落点不变 |
| 诊断 | 延长各 0/100；底座纯旋转 1/100，低于 95%；总偏航不能唯一归因 |
| 新伤恢复 | 延长各 0/100，未触发新版本；其余 6 类均 100/100，最多 20 发 |
| 旧伤恢复 | 延长各 0/100，没有可区分的伤版本；其余 6 类均 100/100、严格 3 发切换 |
| 伤愈识别 | 延长各 0/100，前后落点相同；其余 6 类均 100/100 切回初始版本 |

GP 时间留出中位误差 1.5113→0.1444 mm；加配重后重训 1.3303→0.1582 mm。回退重载最大预测差 0 mm。第 7 节仍有 5 项整体未通过，程序以退出码 1 如实报告。

以下约束已实证，不能通过修改阈值规避：

- **延长杆不可观测**：名义 `beta=gamma=0` 时，延长沿同一条光线移动出光点，交点不变。+20/+40 mm 伤不能由落点检测到，也无法建立独立的伤版本；发现、诊断、新伤/旧伤恢复和伤愈识别不能称为全部达标。
- **偏航伤不可唯一诊断**：`delta1` 与 `psi_b` 仅以和出现。纯底座旋转和 J1 零偏的落点相同，BIC 通常选择参数更少的 H1；预测可恢复，物理伤类型无法保证正确。L2 与 e 也有结构耦合，基线后固定 L2；全参数拟合不等于参数真值唯一可辨识。
- **第二、三批界面验收已通过，真机待验证**：2026-11-13 无头 Chromium 的五种视口及交互实测范围见“运行”一节；仍未验证真实摄像头下的 MJPEG 画面、真机手机浏览器和真实硬件上的急停。软件急停只关激光并拦截后续动作，不能替代硬件急停。
- **原仓库提交受限**：`.git` 只读，创建 `index.lock` 被系统拒绝；里程碑提交使用独立临时 Git 元数据，并最终导出 `reports/milestones.bundle`。代码已写入本目录，原仓库 HEAD 未改动；bundle 可用 `git clone reports/milestones.bundle /一个新的目录` 审查完整提交历史。
- 真机联调、实际标定精度、自动漂移检测与定时重训调度未实现；前两者及自动漂移检测不属于 v0，重训提供手动入口。相机矩阵是仿真配置，不能直接当真机标定结果。

第一批浏览器验证之外，第二、三批也已于 2026-11-13 通过上述五种视口的无头 Chromium 实测；手机视口模拟不等于真机手机验收，MJPEG 测试不等于真实摄像头画面验收，软件急停测试不等于硬件急停验收。
